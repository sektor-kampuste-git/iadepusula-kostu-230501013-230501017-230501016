# Ekran yapılandırması

config.toml okunabilir açık temayı tanımlar. Gizli anahtar/gerçek veri eklenmez.
Tema değişirken yazı, arka plan, kontrast ve hata/engellenme mesajları
birlikte kontrol edilir. AppTest davranışı doğrular; görsel inceleme ayrıca gerekir.
[Arayüz rehberi](../docs/uye3_arayuz.md).
